# LoadSync 0.6.4

**Released:** July 13, 2026

## Features

- **miner:** Add miner uptime metric card (#267)
- **power:** Add Total Power to Power page (#268)
- **nats:** Handle remote engine ESD and load-shed commands (#270)
- Add toast for reboot status on a miner
- **telemetry:** Report Hash Generator vs Hash Hut identity to fleet manager (#273)

## Bug Fixes

- **pdu:** Show limit alongside real value on port power/amperage alarms (#266)
- Keep miner error code dropdowns independent of each other
- **controllers:** Emit one Sentry event per device outage, not per poll (#272)
