# LoadSync 0.8.0

**Released:** November 09, 2026

## Features

- **telemetry:** Send each alarm's first-seen and cleared times (#303)
- **pdu:** Show PDU model and firmware on the Overview tab (#306)
- Optimize auto-balance and add loadcenter power limit (#304)
- **tailscale:** Improve live status and cache profile avatars
- **fan:** Decode full VFD fault tables and add ATV320 fault alarms (#309)

## Bug Fixes

- **engine:** Label engine temperature as coolant temperature (#305)
- **graphs:** Bound graph points for 1W and 1M timeframes (#310)
- **modbus:** Serialize rediscovery (#311)
- **modbus:** Discard undecodable RTU frames instead of raising (#308)
- **ui:** Use a cloud icon on the Fleet Manager cards
- **ui:** Add the missing Tailscale icon

## Refactor

- Use pydantic models instead of dataclasses for plain-data records (#307)
